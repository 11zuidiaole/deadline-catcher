# DeadlineCatcher

一个管 deadline 的小网页。按课程（或者项目）分组，下面列 task，每条都能设截止时间，看一眼就知道哪个快到期、哪个已经逾期。

网址：https://11zuidiaole.github.io/deadline-catcher/

## 功能

- **三层结构**：标题 → task → subtask，subtask 下面还能再分，最多三层
- **Deadline**：每一条都能单独设，不选时间就默认 11:59 PM
  - 显示成「11月20日 周五 · 还有 10 天」这样
  - 快到期的标橙色，逾期的标红色并显示逾期几天
- **三种状态**：点圆圈切换 ○ 未开始 → ◐ 进行中 → ● 完成
  - 半圈的时候可以写进度说明，再选一个预计完成时间
  - 预计完成比 deadline 晚的话会提示
- **说明**：每条都能加一段说明
- **粘贴导入**：从备忘录整段复制过来，会自动分出标题和 task，日期也会自动认成 deadline
- **云端同步**：登录以后手机和电脑数据自动同步，还能找回历史版本
- **统计**：顶部会显示逾期、今天截止、7 天内到期和进行中的数量
- **排序和筛选**：可以按 deadline 排序，也可以隐藏已完成的

## 怎么用

### 基本操作

| 想做什么 | 怎么做 |
|---|---|
| 新建标题 | 右上角「＋ 新建项目」 |
| 加 task | 标题下面的「＋ 添加 task」 |
| 加 subtask | 鼠标移到 task 上点「＋ subtask」，或者点「⋯」→ 添加 subtask |
| 接着写下一条 | 在名字里按回车 |
| 设 deadline | 点右边的日期，或者「＋ deadline」 |
| 加说明 | 「⋯」→ 添加说明 |
| 删除 | 「⋯」→ 删除（要点两次确认） |
| 撤销删除 | 删除后底部会出现「撤销」，5 秒内点 |
| 不小心点开了 | 点空白处就取消，空的那条会自动消失 |

### 选日期和时间

- 日期可以直接打字，不用写年份，比如：`11/20`、`1120`、`Nov 20`、`11月20日`、`明天`
  - 打字的话按回车确认，也可以在月历里点
- 时间点小时、分钟（:00 / :15 / :30 / :45），再选 AM 或 PM
  - 都不选就是 11:59 PM
- 点外面任何地方就会关掉

### 粘贴导入

1. 在备忘录里整段复制
2. 点「粘贴导入」，贴进左边的框
3. 右边是预览，确认没问题点「导入」

识别规则：
- 课程号开头的行（比如 `5559`、`ETEM 5587`）、粗体的行，会当成标题，其他行当成 task
- 能认的日期：`Nov20`、`Nov 15`、`Dec7`、`11/20`、`11月20日`，写了 `11:59pm`、`5pm` 这种时间的也会一起认
- `week 12/13` 这种周数不会被当成日期

从备忘录复制时勾选状态通常会丢，可以在预览里点圆圈改。认错了的话，点那一行的「设为标题 / 设为 task」改过来。

### 手机上

- deadline 显示在任务名下面一行，名字太长会自动换行
- 没设 deadline 的显示「＋ ddl」
- 每行右边的小图标（三条横线）是加说明
- 往左滑出现「删除」
- 一行的字删光后再按删除键，这一行就会删掉；说明删空了再按删除键，说明框会收起来

## 添加到手机桌面

加到桌面以后有自己的图标，打开是全屏的，用起来跟 app 一样。

**iPhone（Safari）**
1. 用 Safari 打开网址
2. 点底部的分享按钮（方框加向上的箭头）
3. 往下滑，点「添加到主屏幕」
4. 名字默认是 DeadlineCatcher，点右上角「添加」

iPhone 上用 Chrome 也可以：点地址栏旁边的分享按钮，再选「添加到主屏幕」。

**安卓（Chrome）**
1. 用 Chrome 打开网址
2. 点右上角「⋮」
3. 点「添加到主屏幕」或「安装应用」

注意：
- 桌面上的 app 和浏览器里打开的网页，数据是分开存的。没登录的话，两边看到的内容不一样，建议登录同步。
- 想换新图标，要把旧的删掉重新添加。删掉桌面图标会把里面没登录时存的数据一起删掉，所以先登录同步再删。

## 数据存在哪

- **没登录**：只存在当前浏览器里
  - 换设备、换浏览器看不到
  - 清除浏览器数据会丢
  - Safari 连续大约 7 天没打开可能会被清掉
- **登录以后**：存在 Supabase 云端，手机电脑同步
  - 底部「历史版本」可以恢复以前的内容
  - 每 10 分钟最多存一份，保留最近 200 份
- 第一次在已经有内容的设备上登录时，如果账号里也有内容，会问你用哪一份，另一份会存进历史版本

## 自己部署

如果想用自己的 Supabase：

1. 在 [supabase.com](https://supabase.com) 建一个项目
2. 打开 SQL Editor，把 `supabase.sql` 整段运行一次
3. Authentication → Sign In / Providers → Email，把 Confirm email 关掉（不关的话，注册后要先去邮箱确认）
4. 把 `index.html` 里的 `SUPA_URL` 和 `SUPA_KEY` 换成自己的 Project URL 和 publishable key
5. GitHub 仓库 Settings → Pages，Branch 选 `main`、`/ (root)`

## 文件

- `index.html`：整个网站
- `supabase.sql`：建数据库表、权限和历史版本用的 SQL
- `manifest.webmanifest`、`icon.svg`、`*.png`：添加到桌面用的名字和图标
